# 🎬 FastAPI Media Fun Project  

> 🚀 A playful yet powerful web app built with **FastAPI**, **Uvicorn**, **SQLAlchemy**, and **ImageKit.io** — where you can **upload, view, and experiment with images and videos** in real-time.  

![FastAPI Banner](https://fastapi.tiangolo.com/img/logo-margin/logo-teal.png)

---

## 🧩 Features  

✨ **Core Highlights**
- 🖼️ Upload and manage **images and videos**
- ⚡ Powered by **FastAPI** + **Uvicorn** for lightning-fast performance  
- ☁️ Integrated with **ImageKit.io** for seamless media storage and CDN delivery  
- 🧠 Uses **SQLAlchemy ORM** for database operations  
- 🧾 Includes structured models, endpoints, and async support  
- 🎨 Easy to extend for creative experiments (filters, thumbnails, metadata, etc.)  

---

## ⚙️ Tech Stack  

| Tool / Library | Purpose |
|-----------------|----------|
| 🐍 **Python 3.11+** | Core language |
| ⚡ **FastAPI** | API framework |
| 🔥 **Uvicorn** | ASGI server |
| 🧰 **SQLAlchemy** | ORM and database management |
| ☁️ **ImageKit.io** | Media storage and optimization |
| 🧩 **Pydantic** | Data validation |
| 🧠 **AsyncIO** | High-performance async handling |
